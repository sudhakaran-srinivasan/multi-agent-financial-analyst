# Sandbox notebooks (not part of the graded deliverable)

These notebooks are early experiments and scratch work kept for history. They are **not** the project's demonstration and may not run as-is (some are Colab-oriented, some use mock data or older code).

For the demonstration of the system, use [../demo_queries.ipynb](../demo_queries.ipynb) (also exported as [HTML](../demo_queries.html) and [PDF](../demo_queries.pdf)).

| Notebook | What it was for |
|---|---|
| `sudhakaran_test.ipynb` | Scratchpad for API experiments: yfinance, Finnhub, OpenRouter tool calling, news pipeline checks. |
| `PARTC_FinalProject_Draft1.ipynb` | Early prototype of the workflow patterns and the evaluator on mock data. |
| `Jeff_News_Ingest.ipynb` (and `.html` export) | Separate Colab-oriented news experiment using LangChain, LangGraph and FAISS retrieval. Has its own dependencies and is not used by the command-line application. |
